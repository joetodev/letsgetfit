# 跟住做 —— 完全離線嘅跟住畫面做運動 App

純 HTML + CSS + JavaScript，冇框架、冇後端、冇網絡請求、冇 LLM。

## 檔案結構

| 檔案 | 用途 |
|---|---|
| `index.html` | 唯一頁面，載入以下檔案 |
| `styles.css` | 手機直向版面，自動跟系統深色／淺色 |
| `data.js` | 動作庫（67 個動作，JS 物件） |
| `engine.js` | 規則引擎：由動作庫砌出一節運動 |
| `anim.js` | 火柴人動畫：每個動作 2–4 個關鍵姿勢，程式補間循環播放（純 SVG，冇圖片檔） |
| `app.js` | 五個畫面、計時播放器、嗶聲、螢幕長亮、記錄 |
| `media/` | 真人示範短片（可選）。`media.js` 列出邊啲動作有片；有片播片，冇片用人偶。用 `../tools/gen_videos.py` 生成 |
| `manifest.webmanifest` + `icons/` | 加到主畫面用 |
| `sw.js` | Service worker，第一次開啟後成個 App 存入快取 |

## 畫面同流程

主頁（揀時長、目標、器材同保護設定）→ 流程預覽（睇晒今節每個動作，可以「換一組」）→ 播放器 → 完成。另有動作庫可以隨時查做法。

播放器由上至下：階段名同剩餘總時間 → 分段進度條（每段一個階段）→ 動畫舞台（公仔循環示範動作，左上角狀態牌、右上角大秒數、底部倒數條）→ 動作名同一句節奏提示（文字做法收埋喺「做法同修正」）→ 「之後」預告 → 上一個／暫停／跳過。

每個動作之前都有一段「準備」：公仔變淡、預先示範下一個動作，等你有時間擺位。分左右嘅動作，右邊會將動畫左右反轉。時間到自動進入下一步。

## 組合規則（engine.js）

1. **時間分配**：每個目標有固定比例。
   - 減肥燃脂：暖身 15%｜間歇 70%｜伸展 15%
   - 筋膜鬆弛：暖身 10%｜滾筒＋球 55%｜伸展 35%
   - 混合：暖身 12%｜間歇 45%｜滾筒＋球 25%｜伸展 18%
2. **過濾同替換**：冇該器材嘅動作剔走；護腕模式將手腕撐地動作換成 `alt.wrist`；零跳躍模式將跳躍動作換成 `alt.impact`。
3. **間歇主訓練**：做 40 秒、休 20 秒。按「心肺→下肢→心肺→核心→心肺→上肢」輪流揀；手腕受力動作唔連續、每圈限量；跳躍動作每圈最多 1–2 個。超過 10 個回合就砌一圈 7 個動作、重複幾圈。
4. **放鬆同伸展**：按優先級揀（小腿、股四頭、臀、足底、胸椎排先，因為跑步同單車最常繃緊呢幾個位），再按身體由下至上排序；分左右嘅動作自動拆成兩步。
5. **時間預算**：每階段填到放唔落為止，餘下秒數平均分返落每個動作，所以總時長一定準確。
6. **變化**：用日期做隨機種子，每日一組；「換一組動作」會重新洗牌。

想加動作：喺 `data.js` 加一個物件，再喺 `anim.js` 用同一個 id 加關鍵姿勢（只需寫髖、肩、手、腳落點，手踭同膝頭由程式計）。想改比例：改 `engine.js` 頂部嘅 `TEMPLATES`。

## 裝落手機（PWA）

Service worker 只可以喺 HTTPS 或 localhost 運作，所以要將成個資料夾放上一個靜態網站：

1. GitHub 開一個 repository，將呢個資料夾入面所有檔案上載（`index.html` 要喺最頂層）。
2. Settings → Pages → Source 揀 `main` branch、`/ (root)`，等一兩分鐘。
3. 手機開 `https://你的帳號.github.io/repo名/`。
4. iPhone：Safari → 分享 →「加至主畫面」。Android：Chrome 選單 →「安裝應用程式」。
5. 開過一次之後，開飛行模式都用得。

Netlify Drop、Cloudflare Pages 都得，做法一樣。之後改咗檔案，記得將 `sw.js` 入面嘅 `APP_VERSION` 加一（只係加減短片就唔使，會自動更新）。

電腦本地試：喺資料夾入面行 `python3 -m http.server 8000`，開 `http://localhost:8000`。

## 已知限制

- 動畫係簡化火柴人，示意姿勢同節奏，表達唔到細節（例如仰臥定俯臥、手掌方向），呢啲要睇「做法同修正」。
- iPhone 開咗靜音掣會聽唔到嗶聲。
- 螢幕長亮需要 iOS 16.4 或以上／Android Chrome。
- 運動記錄只存喺呢部手機嘅瀏覽器，清除網站資料會冇咗。
- 內容係一般運動指引，唔係醫療建議；有傷患或痛楚請先問物理治療師。
